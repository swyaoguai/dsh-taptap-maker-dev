# 资产视觉 QA

## 核心立场

**结构检查 ≠ 视觉可用；编译通过 ≠ 验证完成。**

一个适配层能验证格式、层级、三角面数、包围盒、动画结构 —— 这些都能自动跑。
它**无法**判断：

- 一个左右对称的网格朝的方向对不对（详见 `skills/asset-orientation-qa`）；
- 一次重建出来的模型在视觉上是否可用；
- 车轮/武器是否装在了正确的位置上；
- 一段动画看起来自不自然。

所以：**必须有人（或有视觉能力的模型）看过渲染图和游戏内实拍画面**，
才能说这个资产可用。

> 出处：本文的"结构与视觉分工"及复核维度表整合自 OpenDCAI 的 3AGameFactory 项目
> `agent_skills/asset_qa/README.md` 与 `agent_skills/setting_overview.md`（Apache-2.0），
> 已改写并适配 TapTap Maker。详见仓库根目录 `THIRD-PARTY-NOTICES.md`。

## 什么时候用

- AI 生成的图片/3D/音频要"转正"成项目真实资产时；
- 外部素材（CC0 包、素材站、别人给的文件）导入项目后；
- 占位资产被替换成正式资产后；
- 修完一个视觉问题、要确认"真的改好了"时。

## 两段式分工（别混）

| 阶段 | 由谁负责 | 负责什么 |
|---|---|---|
| 结构检查 | 代码 / 脚本 | 文件存在、格式正确、面数在预算内、有 .meta、引用能加载 |
| **视觉验收** | 人或视觉模型 | 朝向、尺度、风格、附着、穿模、动画自然度、反馈是否对得上 |

**不要试图用代码替代第二段。** 也不要因为第一段全绿就跳过第二段 ——
这正是"游戏能跑但看起来很怪"的成因。

## 验收闭环（关键）

顺序是固定的，**不能跳步**：

```
build → launch → 实际玩一遍 → 录一小段 → 回看 → 记录问题 → 修 → 重录复验
```

几条硬规则：

- ❌ **"能编译"不算验证**。
- ❌ **"能启动"不算验证**。
- ❌ **"日志没有报错"不算验证**。
- ❌ **只看源码或一张截图不算验证** —— 必须真的把主要玩法操作跑一遍。
- ✅ 录一段**小分辨率、短时长**的证据视频（不是宣传片），亲自看。

要把**主要玩法操作**都跑一遍，而不只是启动：移动、跳跃/冲刺、镜头、攻击/射击、
交互/拾取、载具驾驶、受伤与死亡、重生、胜利/失败、暂停，以及承诺过的每个界面。

## 复核维度表

每一条都是「编译 + 结构检查都抓不到」的失败模式：

| 复核域 | 要看什么 |
|---|---|
| **朝向** | 详见 `skills/asset-orientation-qa`。角色面朝移动方向；武器枪口/刀刃朝前且远离身体；载具用前进方向行驶、倒车方向正确 |
| **组合件** | 武器握在握把处、在身体**前方/侧方**而不是插进躯干或浮空；车轮在轮拱**下方**触地，既不陷入车身也不悬空在外；脚踩在地上不浮空不陷地；头盔/背包/盾牌挂在正确挂点并跟随骨骼 |
| **相对尺度** | 角色 vs 武器 vs 载具 vs 门 vs 房间的比例是否可信 |
| **穿模** | 不只是待机姿势要看，**动画过程中**也不能互相穿插 |
| **图像质量** | 网格轮廓与拓扑瑕疵、贴图分辨率、材质响应、接缝、LOD 跳变；场景的构图、地面/墙面连续性、破洞、缺失碰撞面、可视距离、雾 |
| **光照** | 曝光、阴影响当过重或完全缺失、漏光、光照贴图/GI 瑕疵、欠曝发黑或过曝死白、角色与环境的光照方向是否一致 |
| **风格匹配** | 配色、对比度、后处理、氛围是否符合要求（赛博霓虹 / 低多边形 / 写实…）。**一张技术上干净但风格不对的画面，就是不通过** |
| **动态效果** | 粒子/特效在对的时机触发并正确停止（不卡在循环里、不是闪一帧、角色死了特效还留着）；规模与密度合理；挂在正确挂点并跟随；打击/脚步/引擎/UI 的反馈与动画和音效**同步** |
| **可玩性** | 碰撞与物理（不掉穿地面、不卡住、不抖动）；镜头不穿墙不穿角色、构图可用；操作响应、没有反向轴；UI 在测试分辨率下可读、锚定正确、绑定的是真实游戏状态；没有卡顿导致操作不可用 |

## 记录与迭代

每个问题都按这个格式记，才能被真正修掉：

```
现象（在视频里看到什么） → 归属层（资产/导入元数据/玩法逻辑/UI/场景/光照/VFX） → 修法 → 新录像复验
```

**在归属层修根因，绝不跨层打补丁。** 典型反面教材：

- 朝向不对却在 gameplay 里加旋转 → 被其它消费者静默覆盖（见 orientation-qa）；
- 尺度不对却改相机距离 → 所有其它资产跟着错；
- 贴图接缝却在材质里加拉伸 → 换角度又裂。
