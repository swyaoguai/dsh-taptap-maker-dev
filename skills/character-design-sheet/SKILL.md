# Character Design Sheet（角色设定表）

目的：先锁定角色“是什么样”，后面所有图/模型/动画都对齐这张表，避免越画越飘。

## 一张设定表包含

- **三视图 / turnaround**：正面、侧面、背面（必要时 3/4 视）。比例、剪影一致。
- **配色板**：主色/辅色/点缀色 + 材质（金属/布/皮肤）说明。
- **表情表**：中性 + 几个关键情绪。
- **动作/姿态**：待机、移动、核心动作（攻击/技能）关键帧。
- **比例尺**：相对参照物（身高格数），保证场景里不违和。
- **设计意图**：性格、角色定位、识别点（一眼认出的特征）。

## 风格一致的做法

- 先定**剪影**（轮廓辨识度最重要），再加细节。
- 一句话风格描述词固定复用；AI 生图锁 seed + 复用参考图。
- 一个核心识别特征（颜色/形状/配饰）贯穿所有视图。

## 接 TapTap Maker 流程

1. 用自定义生图通道出设定表 / 多视图（纯色底便于抠，见 `taptap-maker-custom-image-gen`）。
2. 要 3D 时，正/侧/背视图作为多视图输入。
3. 动画按 `taptap-maker-animation-fsm` 规划状态与骨骼挂点。
