# Game Feel / Juice

“好玩”很多时候是**反馈密度**堆出来的。按性价比排序：

## 打击 / 命中反馈

- **Hitstop（顿帧）**：命中瞬间暂停 2–6 帧（按力度），双方都停，打击“咬”得住。
- **屏幕震动**：短、幅度小、快速衰减；按事件强度缩放；给玩家一个关掉的选项（晕动）。
- **击退 + 闪白**：受击目标闪白 1–2 帧、沿受力方向位移，恢复用缓动。
- **数字/粒子**：伤害数字跳出、火花/碎屑，命中点生成即消。

## 运动手感

- **缓动曲线**：几乎所有瞬变都别线性——用 ease-out 进、ease-in 出；弹性/回弹用 overshoot。
- **加速度而非瞬时速度**：起步/刹车有过渡；跳跃用非对称重力（上升轻、下落重）更利落。
- **协程/插值**：用 `ValueAnimation` / 协程做缩放、位移、颜色过渡。

## 输入宽容（手游尤其重要）

- **输入缓冲**：落地前按下的跳跃，落地瞬间仍触发。
- **土狼时间 (coyote time)**：离开平台后几帧内仍可跳。
- **点击/触摸热区放大**：命中判定比视觉略大。

## 音画同步

- 关键动作必配音效，音画同帧；高频音效加随机微音高避免腻。
- 低成本高回报顺序：音效 → hitstop → 粒子 → 屏震 → 闪白。

每加一项都要**实机手感验收**，过量 juice（长屏震、满屏粒子）反而难受。
