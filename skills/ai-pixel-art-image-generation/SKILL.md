# AI 生图做游戏素材

目标是“能直接用”的素材，不是好看的插画。重点是**风格一致 + 可抠图 + 尺寸可控**。

## 提示词模板

`<主体> + <风格词> + <视角> + <背景要求> + <画面占比>`

- 主体只留**一个**核心描述，删掉易冲突修饰（金边/魔法/宝石一起写模型会挑一个执行）。
- 风格词固定复用（如“扁平矢量/像素风/卡通厚涂”），全套素材同一句。
- 视角统一（正交/等距/正视），批量才协调。
- 显式写“主体占满画面、居中”。

## 透明素材 = 纯色底 + 自己抠

生图模型通常**不给真 alpha**（写 transparent 会得到假棋盘格）。做法：

1. 让它出**纯色底**（洋红 `#FF00FF`，美术里几乎不出现）。
2. **边缘泛洪**抠底：从四条边 BFS 删与边缘连通的底色像素，主体内部不碰（别全局删色相）。
3. 裁到不透明外接框（留 ~4% padding）→ 缩放到目标尺寸。

## 尺寸

多数端点只认 `1024x1024 / 1024x1536 / 1536x1024`。要 256 图标：出 1024 再缩。等距/精灵表尺寸统一，便于拼图集。

## 批量

- 每张可能随机被 `content_policy` 误伤 → **原样退避重试**（15s 起 +8s，最多 6 次），别改词。
- 风格一致靠固定 seed + 固定风格词；需要延续角色就带参考图。
- **逐张目视验收**：主体占比太小会被抠剩一小团。

## 落地

走本插件自定义通道（`taptap-maker-custom-image-gen`，不花 Maker 额度）；成品入 `assets/` 并补 `.meta`，中间图留在 `assets/` 外。
