## 3.2

对齐 2026-10-23 的站点前端：多参考图编辑、分辨率档位、质量档位、签到日历与补签。
前端证据来自 `pai.zaiduyu.top` 线上打包产物（`/app/page` 与 `app/checkin` 分块），不是按 OpenAI 通用协议猜的。

### 新增

- **多参考图编辑**：`--image` 支持一次传多张（`--image a.png b.png` 或重复 `--image`），最多 **16 张**（前端常量 `Y=16`）；单张 ≤20 MiB、合计 ≤64 MiB；按真实文件头校验图片，重复内容自动去重；首张为待编辑主图。
- **multipart 字段名随张数切换**：单图 `image`，多图重复 `image[]`（前端 `l.length>1?"image[]":"image"`）。
- **JSON 多图协议**：自定义路由模型（`modelImageRouting.mode=custom`）与 `gpt-image-2-2k/4k`、`gpt-image-2.5-flare/sunburst` 改走 `Content-Type: application/json` + `images:[{image_url:"data:..."}]`，与前端一致；其余模型仍走 multipart。
- **`--resolution 1K|2K|4K`**：按前端档位基准表整数倍放大尺寸（`1:1` 基准 1024，`3:2` 基准 1008x672 等），例如 `--ratio 16:9 --resolution 4K` → `3840x2160`。
- **`--size 宽x高`**：除原有固定尺寸外，可直接指定任意像素（边长 64-8192，总像素 ≤1 亿）。
- **`--quality`**：`auto/low/medium/high/standard/hd`，按前端逻辑透传到 `quality` 字段，不传则交给上游。
- **`--makeup YYYY-MM-DD`**：补签，先读签到状态确认启用且机会 >0，已签到的日期直接拦下，不消耗机会。
- 比例新增 `4:5`、`5:4`。
- 多图时自动补一段角色说明（图 1 主图、素材图不得覆盖主图构图与身份），单图不改写用户原话。
- `gpt-image-*`（除 `gpt-image-2`）多图时按前端规则带 `input_fidelity=high`。

### 改进

- 编辑固定按 `n=1` 并发发起多次请求（网站就是这么做的，避免上游忽略 `n` 导致张数不符）。
- 每次图片请求带唯一 `Idempotency-Key`（前端同款机制），降低代理或重试造成重复扣费的风险。
- `--checkin` 先查状态，已签到直接返回，不重复提交；签到日期按 UTC+8 判定。
- `--history` 同时读顶层与 `overview` 内嵌流水数组，修掉旧版只查顶层、读不到流水却输出全量定价的问题。

### 其他

- 版本号 `3.2.0`；离线回归脚本覆盖尺寸档位、参考图校验/去重、三种请求体格式、幂等键与并发批次，全程不联网、不扣积分。

## 3.1

适配站点把生图改为「直接请求上游」后的行为，修掉默认路径必失败的问题。

### 修复

- 站点已下线异步任务接口 `/api/image-jobs`，调用会返回 **HTTP 409**（提示「图片生成已改为直接请求上游」）。旧版本只对 `404 / 405 / 501` 做异步→同步回退，导致 409 时默认路径直接报错。
- 现在图片链路**默认直接走同步生图接口**，不再依赖已下线的异步任务。
- `--async` 强制走旧异步任务时，把 `409`（以及 `410`）并入自动回退集合 `ASYNC_FALLBACK_STATUSES = {404, 405, 409, 410, 501}`，命中后打印一行提示并自动回退同步，不再直接抛错。

### 新增

- `--async` 开关：仅在需要兼容旧行为、手动尝试异步任务接口时使用。
- `GOTCHAS.md`：汇总真实跑图踩过的坑（异步 409、同步耗时、未标价模型与 `--strict-balance`、Chat/Images 链路差异、余额隐私等）。

### 变更

- `--sync` 变为兼容旧参数：站点异步接口下线后脚本本来就默认同步，加不加效果相同。

## 3.0

适配站点多模型更新，生图前先选模型、看价格、看余额。

### 新增

- `--models`：列出网站实时支持的全部生图模型、每张积分消耗和当前积分余额，不生成图片、不消耗积分。
- `--plan`：只展示所选模型的本次积分预检（模型、单张消耗、张数、预计总消耗、当前积分、预计剩余、调用接口），不提交生图请求。
- `--model` 支持模型 ID 和显示名，匹配时忽略大小写和空格，例如 `gpt-image-2`、`Z-image`、`Banana 4k`。
- 模型目录从 `/api/config` 与 `/api/credits` 动态读取，并过滤非生图模型；站点上新模型或调价后无需改脚本。
- 生图与编辑前统一打印预检横幅：模型、单张积分、数量、预计总消耗、当前余额、预计剩余、调用接口。
- 自动识别两种调用链：`images`（GPT 系列，走异步任务）和 `chat`（Gemini / Grok / Z-image，走 Chat 多模态同步接口）。
- 按模型自动附加 `X-Image-Routing` 请求头，兼容站点前端的多模型路由逻辑。

### 改进

- `--strict-balance` 改为按「余额 ≥ 单张积分 × 张数」判断，余额不足时不再提交。
- 未标价模型在列表和预检中显示「未标价」，不再当成 0 积分；`--strict-balance` 遇到未标价模型会直接停止提交。
- `--models` 输出按「启用状态 → 单张积分 → 模型名」排序，并标注调用接口和模型简介。
- 编辑请求按模型路由分流：Images 模型走 multipart 编辑接口，Chat 模型走多模态消息接口。
- 预检中显示「调用接口：Images / Chat」，便于判断本次是异步任务还是同步调用。

### 变更

- 移除「模型固定为 gpt-image-2、其他模型直接拒绝」的限制，改为以站点实际模型列表为准。
- Chat 类模型固定走同步接口，异步任务接口仅用于 Images 模型。
- `--model` 不再隐藏，模型未指定时使用站点 `defaultModel`，站点未配置时回落 `gpt-image-2`。

## 2.1

### 变更

- 默认张数由 3 改为 1，不再在用户没要求时多生成图片和多消耗积分。
- `--n` 上限由 3 提升到 12，超过 3 张时按网站 3 并发自动分批提交，例如 5 张为 3+2，6 张为 3+3。

## 2.0

围绕 `pai.zaiduyu.top` 的实际能力重写，明确定位为该网站专用生图工具。

### 新增

- `--ratio` 比例参数，支持 `1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`16:9`、`9:16`，按网站实际映射自动换算尺寸。
- 默认使用网站异步任务接口，创建任务后轮询结果，更适合长时间生图。
- 真正的三并发：生成多张时并行创建最多 3 个任务，不再串行等待。
- `--balance` 查询总积分、永久积分、限时积分和最近到期时间。
- `--history` 查询积分交易与模型用量记录，配合 `--history-limit` 控制条数。
- `--checkin` 手动签到，仅显式调用时执行。
- `--image` 图片编辑，支持换背景、改服装、扩图等本地图片修改。
- `--timeout` 与 `--retries`，可自定义超时与重试次数。
- `--warn-balance` 低余额提醒，`--strict-balance` 余额不足时阻止提交。
- `--sync` 回退开关，可绕过异步任务直接调用同步生成接口。

### 改进

- 修正 `9:16` 尺寸：由近似的 `1024x1536` 改为网站实际使用的 `864x1536`。
- 503、429、502、504 等临时错误自动重试，遵循 `Retry-After`；`image_capacity_limit` 至少等待约 20 秒。
- 默认超时由 180 秒提升到 300 秒，与文档要求一致。
- 同名文件自动追加序号，不再覆盖同一天同描述的旧图。
- 未指定扩展名的输出路径自动补 `.png`。
- 错误信息统一提取接口返回的可读文案，登录失败不再盲目重试。
- 强制 UTF-8 输出，修复 Windows 终端中文乱码。
- 支持接口返回 `b64_json`、`data:` 内联图片和图片直链三种结果。

### 变更

- 模型固定为 `gpt-image-2`，移除对外的模型切换能力；传入其他模型会直接拒绝。
- 账户类操作（积分、历史、签到）必须显式调用，不会在生图流程中自动执行。
