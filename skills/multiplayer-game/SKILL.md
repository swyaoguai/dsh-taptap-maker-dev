# Multiplayer Game（通用网络模型）

## 第一原则：服务端权威

关键状态与判定（位置、血量、命中、掉落、分数）由**服务端**决定；客户端只上报输入、做表现。否则必被作弊。

## 同步模型（按玩法选）

- **输入同步 / 帧同步**：确定性模拟，各端跑同样逻辑（适合 RTS/格斗；要求严格确定性）。
- **状态同步**：服务端算，广播状态快照（适合大多数动作/射击/休闲）。多数情况选这个更省心。

## 隐藏延迟

- **客户端预测**：本地立即响应输入，收到服务端权威态后**和解**（回滚重放或平滑纠正）。
- **插值**：对其他实体用“过去一点”的状态插值，画面平滑。
- **延迟补偿**：命中判定时服务端回放到客户端开火时刻（射击类）。

## 一致性 / 边界

- 带宽：只发变化量、按重要性/距离降频（兴趣管理）。
- 晚加入/重连：能把当前世界态同步给新连接。
- 时间：统一服务端时间，别信客户端时钟。
