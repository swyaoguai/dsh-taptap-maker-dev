# Game Designer

## 先定核心循环

一句话写清玩家**反复做什么**，以及每轮的 行动 → 反馈 → 奖励 → 变强/变难。核心循环要在 30 秒内能体验到一次。

- 例：移动躲避 → 命中敌人 → 掉金币 → 升级/解锁 → 更强的敌人。
- 循环之上再叠**中期目标**（关卡/任务）与**长期目标**（收集/排行/成长）。

## MDA 透镜

- Mechanics（规则）→ Dynamics（运行时行为）→ Aesthetics（玩家感受）。
- 想要的“感受”倒推“规则”：要紧张感就给资源稀缺+时间压力，要爽就给成长+清屏。

## 首分钟（上手）

- 不靠文字墙教学，用**关卡设计**教：先给安全环境让玩家自己发现操作。
- 第一分钟必须出现一次“成功/爽点”，否则留不住。

## 难度曲线

- 锯齿上升：难—缓—更难，给喘息。
- 用“教学关→应用→变体→组合考验”的节奏引入每个新机制。
- 失败要廉价（快速重来），惩罚别劝退。

## 留存钩子（克制使用）

- 每日目标 / 连续登录 / 阶段解锁 / 收集图鉴 / 排行榜。
- 钩子服务玩法，不是反过来；别为留存破坏核心乐趣。

## 数值与反馈

- 成长要**看得见**（数值、外观、能力都变）。
- 正反馈循环（越强越爽）要有上限/配平，避免滚雪球碾压或通胀。

落 TapTap Maker 时：核心循环 → 最小可玩原型（灰盒）→ 手感（见 `game-feel`）→ 内容扩充。先让一个循环好玩，再堆量。
